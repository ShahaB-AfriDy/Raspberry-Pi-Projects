# 🤖 Raspberry Pi Robotics Projects

Welcome to my **Raspberry Pi Projects Workspace** — a collection of robotics and automation projects developed using the Raspberry Pi platform.  
This repository includes experiments in computer vision, sensors, object tracking, robot movement, and real-time video processing.

---

## 📁 Project List

| Project | Description |
|----------|--------------|
| **Angels_opencv** | OpenCV-based vision project for image/video analysis |
| **Deviation Object** | Object deviation detection using computer vision |
| **GPIO_Zero** | Basic experiments using GPIO Zero library to control sensors and actuators |
| **Human Following Robots** | Robot that follows a human using camera input and motion tracking |
| **Object Tracking Robot Pi** | Raspberry Pi robot for real-time object tracking |
| **RC Driving** | Remote-controlled robot driving system |
| **Robot Streaming Live** | Live video streaming robot using Raspberry Pi camera |
| **Sound Sensor** | Detects and responds to sound inputs using a sound sensor module |
| **Video Recording** | Record video using Raspberry Pi camera module |
| **Zip Project** | Miscellaneous or archived Raspberry Pi code |
| **Raspberry_Pi_Two_Wheel_1.py** | Script for two-wheel robot control |
| **Raspberry_Pi_Two_Wheel_Classes.py** | Modular version of two-wheel robot control system |
| **control_webcam_servo_motor.py** | Control servo motors through webcam input |
| **tieske_github_io_rpi_gpio_modules_GPIO_html.pdf** | Reference documentation for GPIO modules |

---

## ⚙️ Technologies Used

- **Platform:** Raspberry Pi 3/4  
- **Programming Language:** Python  
- **Libraries:** OpenCV, GPIO Zero, time, threading  
- **Hardware:** Ultrasonic sensor, servo motor, Pi camera, sound sensor, motor driver  

---

## 🚀 Objectives

- Learn and explore **robotics and automation** with Raspberry Pi  
- Implement **real-time computer vision** and **object tracking**  
- Build simple yet powerful **AI-driven robotic systems**  
- Practice hardware-software integration for IoT and embedded systems
